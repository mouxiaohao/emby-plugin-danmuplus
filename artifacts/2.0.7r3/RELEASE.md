# emby-plugin-danmuplus 2.0.7r3

本版本完成智能匹配电视遥控器导航、临时季后缀重新匹配和内建官方
CORS 路由维护更新。具体路由地址只保留在后端实现中，不在配置、管理
页面、发布说明或前端资产中展示。

## 主要变化

- 智能匹配弹窗支持 D-pad 四向几何导航、OK/Enter/Space 选择、Tab 闭环、
  输入框编辑例外和父子页面焦点恢复。
- 遥控器向上移动到标题栏关闭按钮时，智能匹配正文同步回到顶部，不接管
  Emby 宿主页面滚动。
- 重新匹配某个临时季时，自动撤销该段及后续临时季并合并回唯一未匹配
  后缀；更早映射和普通单段移除语义保持不变。
- 更新后端维护的官方 CORS 路由；配置模型、配置 API 和前端不公开或保存
  具体地址。

## dd-danmaku 1.48.1 自用资产

本 Release 同时提供独立的 `dd-danmaku.CustomCssJS.js` 和完整源码包。它
与 `DanmuSmartMatch.CustomCssJS.js` 是两个不同组件，也不是插件 DLL 的必需
依赖。

该脚本基于 dd-danmaku v1.47，仅为维护者个人自用需求维护。没有向上游
提交这些改动、发起 PR 或请求合并的计划，也不代表上游项目认可该构建。
分发物保留原作者信息、完整 dd-danmaku MIT 许可、Danmaku 2.0.8 MIT 许可、
修改说明和 SHA-256。
