# emby-plugin-danmuplus 2.0.3r9

## 更新内容

- 完成 2.0.3r1 至 2.0.3r9 的季度显式映射、重新匹配、受限搜索、搜索质量、父季度范围、按需候选详情与临时季度交互改进。
- 普通季度严格忽略混入的 S00、其他季度和父季度未知单集；真实 Season 0 仍可单独匹配。
- 修复芒果 TV 搜索接口兼容性，提供商失败互不影响。
- 修复手动自定义关键词的跨语言别名过滤问题，保留空格、字面量 `+`、标点和非 ASCII 查询；自动匹配继续使用严格标题证据。

## 从 2.0.2r4 到 2.0.3r9 的版本节点

- **2.0.3r1**：建立复合季度显式映射、稳定连续分组、精确来源单集下载/重试和重启恢复，不改写 Emby 原有季度成员关系。
- **2.0.3r2**：加入移除、恢复和范围内重新匹配；建立 10 秒单提供商、30 秒交互、45 秒自动操作预算及全局/单站并发限制。
- **2.0.3r3**：收紧身份搜索词和候选质量，按提供商公平投影；支持部分季度显式确认与仅下载已确认范围。
- **2.0.3r4**：引入父季度感知规划上下文与计划代际；V20 前端展示权威分数/来源/逐集映射并隐藏内部标识。
- **2.0.3r5**：整剧跳过 Season 0，普通季度严格排除混入的 S00、其他季度和未知父季度单集；真实 Season 0 仍可单独匹配。
- **2.0.3r6**：候选详情按需加载并使用短期证据与目标绑定；统一对话框级强制刷新状态。
- **2.0.3r7**：统一临时季度手动匹配/重新匹配入口，展示本地与来源标题，修正忙碌状态和重复分数呈现。
- **2.0.3r8**：迁移芒果 TV 搜索到已验证接口并规范化响应，失败保持提供商局部隔离，前端和映射协议不变。
- **2.0.3r9**：手动自定义关键词仅作为发现输入，保留跨语言、空格、字面量 `+`、标点和非 ASCII 查询候选；自动匹配仍执行严格标题证据过滤。
